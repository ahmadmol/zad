# دليل تجربة النسخة المحلية

هذه نسخة اختبار محلية. لا توجد مصادقة هاتف أو مزامنة أو تواصل بين مستخدمين على أجهزة مختلفة. حالة «منتهٍ محليًا» ليست إثبات تسليم تبرع.

1. ثبّت APK المرفق من تقرير الإصدار. احتفظ بنسخة بياناتك؛ لا تحذف تثبيتًا شخصيًا لتجاوز اختلاف التوقيع. حزمة QA المعزولة لها معرّف مستقل عن التطبيق الأصلي.
2. افتح القرآن دون إنترنت: تحقق من السور، وابحث بـ«الله لا اله الا هو الحي القيوم»، وانتقل إلى 2:255 ثم الصفحة604 وجزء30. جرّب الحفظ والرجوع وتغيير حجم الصفحة والقارئ، ثم أغلق التطبيق وأعد فتحه. الكريم والزخارف ثابتان في الوضعين.
3. التلاوات الفعلية غير مفعّلة حتى اعتماد حقوق التسجيلات. اختيار القارئ محفوظ. اختبار ملف WAV الاصطناعي موجود في APK الاختبارات فقط ولا يقدَّم كتلاوة.
4. افتح الأحاديث: المكتبة العربية من HadeethEnc v1.7.0، وتفاصيل كل نص تضم مرجع الناشر وحكمه وشرحه وفوائده. جرّب البحث والمفضلة وإعادة الفتح والنسخ والمشاركة.
5. الأدعية تضم39 قراءة موثقة:30 آية كاملة و9 أحاديث كاملة السياق. تصنيفها للتصفح لا يضيف فضلًا أو توقيتًا تعبديًا. افتح كل الأقسام السبعة وجرّب البحث والحفظ والمشاركة.
6. اختر مدينة وطريقة حساب للصلاة. الحساب محلي؛ قارنه بالتقويم المعتمد لديك. جرّب رفض الأذونات ثم السماح بها وتعديل التذكير وإلغائه. دقة موعد التنبيه تحت قيود البطارية تتطلب تجربة هاتف فعلية.
7. القبلة تستخدم الموقع المختار أو المحفوظ، وتوضح غياب الحساس أو ضعف المعايرة. اتجاه المحاكي ليس شهادة دقة بوصلة. يلزم هاتف وحركة ومعيار اتجاه معروف للتحقق النهائي.
8. الأمثلة المجتمعية تحمل DEMO ولا أرقام اتصال لها. أنشئ ملفًا محليًا وعرضًا وطلبًا، ثم عدّل الوصف والحالة واحذف مع التأكيد. إعادة ضبط Demo يجب أن تُبقي سجلاتك. تسجيل الدخول المحلي ليس تحقق هوية.
9. جرّب صورة منفردة وألبومًا، ثم إعادة الفتح وترتيب الغلاف. حذف سجل لا ينبغي أن يحذف صورة يستخدمها سجل آخر أو الصورة الشخصية.
10. الفيديوهات تستخدم مشغّل YouTube أو تفتح المصدر خارجيًا. عند منع التضمين أو غياب الشبكة اعتمد الحالة الظاهرة؛ لا تُفهم الصورة المصغرة كدليل تشغيل أو بث حي. لا يُنزّل المحتوى أو يُستخرج صوته.
11. بدّل Light/Dark وحجم خط النظام1.3، وجرّب لوحة المفاتيح والتمرير والرجوع. أرفق اسم الشاشة والحجم والوضع وخطوات تكرار أي عطل؛ نتائج اللقطات والاختبارات المفصلة في تقرير الإصدار.

لم تكتمل مراجعة مصادر المعاني التحريرية للأسماء، وموسوعة الأذكار الشاملة، والتفسير المرخص. لا يُعرض أي منها كاعتماد شرعي مكتمل. راجع CONTENT_SOURCES_AND_LICENSES وQA_BUG_REPORT للحالة الدقيقة.
