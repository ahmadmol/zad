## قيود محسومة من المستخدم

- التخطيط فقط؛ إنشاء الوثائق داخل docs/planning فقط. لا تعديل Kotlin أو Gradle أو Manifest أو الموارد أو البيانات، ولا Commit/Push/Reset/Rebase.
- Kotlin + Compose + Material3، والحفاظ على الهوية وDark Emerald/Charcoal وصفحة المصحف والنص والمصادر.
- لا تثبيت أو فحص هاتف خلال التخطيط. أي اختبار Android لاحق حصريًا Xiaomi 23129RAA4G / ac190123. Emulator/AVD ممنوعان.
- لا Backend أو تبرعات أو مجتمع حقيقي الآن، ولا تجاوز YouTube أو تنزيل غير مصرح، ولا Analytics جديد دون قرار خصوصية.
- الميزات المستقبلية ليست شرط Beta الحالي. كل دفعة Gemini تتوقف لاعتمادها. لا إرسال تلقائي لأي أمر.

هذه القيود لا تحتاج أسئلة تأكيد متكررة. موافقة الخطة لا تساوي إذن reboot أو تغيير وقت الجهاز أو نشر منتج أو مراسلة الآخرين.

## إغلاق القرار أو الحاجب

كل قرار معتمد يسجل ID والمالك وتاريخ Asia/Damascus والخيار وسببه ونطاق التوزيع أو البيانات والمستند المؤيد والمهام المتأثرة والمخاطر المقبولة وموعد المراجعة إن لزم. وجود هذه الخطة لا يجعل القرار Approved.

كل حاجب خارجي يسجل الجهة المسؤولة والوثيقة الناقصة وما يبقى متاحًا ضمن النطاق الحالي وفحوص التفعيل بعد الموافقة. PendingLicense لا يغلق بتغيير زر أو HTTP probe.

بدء G0-01 يحتاج اعتماد الخطة واختيار الدفعة فقط. المهمة تسوية أدلة ولا تحتاج قرار مشغل جديدًا أو إذن هاتف. أول أمر جاهز في [ملف أوامر Gemini](IHSAN_GEMINI_EXECUTION_PROMPTS.md)، ولا يرسل تلقائيًا.

## أثر المراجعة النهائية على القرارات والمخاطر

اعتماد هيكل8مراحل و40مهمة مبدئي، وليس إذن بدء التنفيذ أوفتح الهاتف. لا قرار جديد مطلوب لإجراء G0-01 بعد اعتماد المراجعة؛ الدفعة تعلن نقص الدليل ولا تختار سياسة منتج نيابة عن المالك.

- D-01 يحدد قبول التضمين والبديل الرسمي ونطاق عينات media، وD-02 يحدد داخلي/عام وهوية الشهادة، وD-10 يثبت حقوق التوزيع. هذه لازمة لحكم القبول المعني، ولا تمنع تدقيق الأدلة المكتبي.
- D-03..09 وD-11 تبقى لدفعات الميزات والسياسات التابعة؛ لا تجعلها شرط Beta الحالي إذا لم تغير سلوكه أوتدخل نطاق توزيعه.
- R-01: hash المصدر لا يساوي hash APK؛ عينة8ملفات لا تثبت كامل source→artifact؛ بياناتinstallation التاريخية لا تثبت ما هو مثبت اليوم. إذا غابت وصلة يبقى القبولCurrent Pending مع حفظPASS التاريخي بنطاقه.
